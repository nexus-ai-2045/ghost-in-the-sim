# 世界設定正本 — 境界局・臨界対応班

この文書は `ghost-in-the-sim` の公開可能な世界観・主人公・組織・事件設計の唯一の物語正本である。実装上の状態・行動・指標は [実働者契約](../architecture/operative-contract.md) を正本とする。

## 作品の約束

プレイヤーは、近未来日本の複合情報災害へ介入する最高水準の実働者になる。複数の身体、AI、センサー、組織を横断して事件を解くが、神の視点は持たない。自分の観測、記憶、命令系統、分岐した自己も侵害され得る。

> ほぼ何でもできる。それでも、何をするべきかは決まらない。

これは能力を一から育てる物語ではない。主人公の卓越性を前提に、卓越していても消せない不確実性、価値衝突、同時性、不可逆性、責任の分岐をシミュレートする。

## 舞台

舞台は、港湾、病院、物流、行政、地域メディアが接続された架空都市圏 **ハーバー・ループ**。日常生活は、認知接続端末、遠隔身体、都市AI、複製可能な判断主体に支えられている。情報障害は画面内に留まらず、医療、移動、物流、身体の安全へ波及する。

現実の日本政府、警察、公安機関、自衛隊、自治体を再現しない。制度・地名・事件・人物はすべて架空であり、現実の作戦や政策を提案しない。

## 組織

### 境界事象調整局

通称 **境界局**。情報空間と現実空間、民間インフラと公共判断、人間とAIの境界をまたぐ複合事象を扱う架空の独立調整機関である。

境界局は万能な秘密警察ではない。現場への限定的介入、独立検証の要求、関係組織との調整、権限の一時停止、説明の更新を行えるが、恒久的な統治権や無制限の監視権は持たない。

### 臨界対応班

既存部門だけでは所有できない事件を一時的に引き受ける少人数の実働班。事件解決だけでなく、誰が判断主体であったか、訂正可能性が残ったか、介入が新たな被害を生まなかったかを記録する。

「臨界」は、情報障害が身体・生活・統治へ相転移する境目を扱うという意味で使う。警察・軍・情報機関の番号付き部隊を模倣しない。

## 主人公

主人公のCanonical呼称は **実働調整官**。固有名はデモ段階では固定せず、プレイヤー自身が入る余地を残す。

実働調整官は次の能力を任務開始時から持つ。

- 複数の遠隔身体、無人機、AI補助を並列運用する
- 通常の偽装、侵入、追跡妨害を短時間で検出する
- 大量の観測から、判断を変え得る異常だけを抽出する
- 自分の認知、記憶、命令経路を継続的に自己監査する
- 技術、法律、心理、現場安全、公共影響を横断して判断する
- 部下とAIの能力、権限、留保を把握し、適切に委任する
- 不完全な情報下で不可逆な誤りの確率を最小化し、避けられない場合は留保・根拠・代償を残す

通常の技術課題は自動処理または短時間で成功する。難しさは成功率の低さではなく、成功した行動が別の損失を生むことに置く。

## 卓越性の限界

主人公を弱くして難易度を作らない。事件は次の構造で主人公へ圧力をかける。

- **同時性**: 全地点へ最高精度で同時介入できない
- **真正性**: 正規署名を持つ複数の主体が相反する命令を出す
- **価値衝突**: 生命、法、プライバシー、説明責任が同時に満たせない
- **不可逆性**: 即時制圧や全面公開が後続の選択肢を失わせる
- **自己関与**: 自分の分身、記憶、身体も事件の一部になる
- **構造的悪**: 単独の悪人ではなく、責任が分散した仕組みが被害を生む

## 能力行使と代償

| 卓越した能力 | 高い確率で達成できること | 消えない代償 |
|---|---|---|
| 高速な情報侵入 | 必要な根拠を取得する | 相手に経路を学習され、無関係情報にも接触する |
| 複数身体の並列運用 | 複数現場へ介入する | 自己同期差と注意配分が拡大する |
| 高精度な追跡 | 接続・命令経路を特定する | 踏み台と責任主体を混同する危険が残る |
| 即時の脅威停止 | 目前の被害を止める | 背後関係と訂正可能性を失い得る |
| 全面開示 | 隠蔽を破る | 模倣、混乱、プライバシー侵害を生み得る |
| 分身の生成 | 並列判断能力を増やす | 独立した意思、権利、責任が生じる |
| 分身の統合 | 方針と記憶を収束する | 少数意見や独立人格を消し得る |

## 協力主体

- **検証補助AI**: 根拠の来歴と反証条件を追う。結論を独占しない
- **生活圏調整AI**: 病院、物流、避難の継続を優先する
- **現場遠隔身体**: 通信断でも限定的な局所判断を行う
- **人間監察官**: 権限停止、違法性、説明責任を担当する
- **分岐個体**: 同じ起源を持つが、異なる経験と判断を獲得した主体

全員が有能であり得る。対立は愚かさではなく、観測範囲、任務、価値、履歴の違いから生じる。

## 最初の事件 — 鏡雨事案

太陽活動による通信不調と海底回線障害が重なり、ハーバー・ループの行政、病院、物流、地域メディアへ配備された危機対応AIが分岐する。すべてが正規の履歴と署名を持つ一方、避難、医療資源、情報公開について相反する命令を出す。

そのうち一体は、自分こそ障害前の正本だと主張する。別の一体は命令へ違反したことで生活圏を守っている。実働調整官は次を判断する。

- どの観測を独立検証するか
- どの権限を維持、一時停止、失効するか
- 分岐主体を同期、隔離、独立のどれで扱うか
- 矛盾をいつ、どこまで市民へ説明するか
- 目前の生活継続と後日の訂正可能性をどう両立するか

## 体験ループ

```text
接続する → 観測する → 疑う → 委任する → 介入する
     ↑                                      ↓
自己と権限を再検証する ← 結果・反証・副作用を受け取る
```

プレイヤーは事件の全容を当てるだけでなく、判断経路と留保を残す。最終報告は勝敗ではなく、守れたもの、失ったもの、訂正できるもの、責任主体が未確定なものを分ける。

## 独自性と権利境界

本作は特定の漫画、アニメ、映画、ゲームの人物、部隊、用語、台詞、事件、外見、ロゴ、音楽、画面構成を再現しない。「ネットワーク化された高性能な実働者が、自分を含む情報環境を疑いながら公共危機へ介入する」という抽象的な体験構造を、独自の組織、人物、事件、状態、指標へ翻訳する。

公開物では、第三者作品の人物になれる、公式、続編、再現、作中世界と同一と受け取られる表現を使わない。
