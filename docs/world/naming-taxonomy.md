# 命名体系正本

神話名は飾りではなく、読者が役割と危険の種類を推測するための分類語彙として使う。出典伝統を混ぜず、同じ系統には原則として同じ責務を割り当てる。

| 系統 | 主な責務 | 採用・予約例 |
|---|---|---|
| ギリシャ・ローマ | 都市、行政、基盤、権限 | ポセイドン、トライデント、ネレイド、オケアノス、アイギス、ゼウス、モイライ、ヘルメス、アリアドネ、ヘファイストス |
| 日本の自然・説話 | 現場AI、観測現象、分岐主体 | カナメ、ウツセミ、ミナモ、シラヌイ、ヨスガ、カゲロウ、オボロ、マヨイガ、ククリ、アマノジャク |
| 北欧 | 監視、境界警戒、通信 | ヘイムダル、フギン、ムニン、ビフレスト |
| エジプト | 本人性、記憶、死、審判 | オシリス、アヌビス、マアト |
| インド・仏教 | 複数身体、循環、分散認知 | アヴァターラ、インドラ網、輪廻 |
| メソポタミア | 旧基盤、洪水、最古層記録 | エンキ、ウトナピシュティム |
| ケルト | 治癒、共同体、回復 | ブリギッド、ディアン・ケヒト |
| クトゥルフ神話 | 認識不能な境界事象 | ダゴン、ハスター、ヨグ、ニャル、アザトース、シュブ、ルルイエ状態 |

クトゥルフ系は恐怖値ではなく、認知完全性、自己境界、観測汚染、概念侵食、記述不能、相互観測不一致を表す分類に限定する。原典・後世の追加設定・翻訳固有表現を区別し、名称以外の表現を転用しない。

命名追加時は、(1)責務が既存系統に適合する、(2)既存名と混同しない、(3)出典と権利境界を追記する、(4)公開前に人間が束としてレビューする、を必須とする。
