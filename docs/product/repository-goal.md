# リポジトリゴール

## ゴール

`ghost-in-the-sim` は、2036年の海洋複合都市圏ポセイドンを舞台に、卓越した実働調整官・御影冴が、複製可能な人格・身体・権限をめぐる公共危機へ介入する**再現可能な意思決定シミュレーター**を作る。

面白さの核は命中率や成長ではない。高性能な主体でも避けられない同時性、真正性、価値衝突、不可逆性を、同じ外生事象・同じseedの反実仮想比較として体験し、判断の結果と代償を説明可能にする。

## 完了の定義

- 同一scenario・seedで複数統治方式を比較できる。
- すべての判断に観測、権限、反証条件、結果、代償が残る。
- 御影の注意予算と自己監査、真壁の独立停止要求が状態遷移に効く。
- 鏡潮事案を最後まで実行し、生活継続、誤命令、訂正時間、異議保存、権限収束、不可逆損失を比較できる。
- 設定採用、契約済み、実装済み、実測済み、公開承認済みを混同しない。

## 非ゴール

- 現実の公安、警察、軍、自治体の作戦再現
- 侵入・攻撃手順の実用化
- 生成AIが物語とルールを同時に改変する仕組み
- 特定作品の本文、人物、部隊、外見、事件、画面の複製
- 単一スコアで倫理的正解を決めること

## 成果物の所有

| 正本 | 所有するもの |
|---|---|
| `docs/world/setting-bible.md` | 時代、舞台、制度、不変条件 |
| `docs/world/characters.md` | 人物、関係、ユーモア、価値衝突 |
| `docs/world/naming-taxonomy.md` | 神話命名の役割と境界 |
| `docs/world/cases.md` | 事件候補と実装状態 |
| `docs/architecture/*` | 状態、行動、指標、再現性契約 |
| `docs/roadmap.md` | 実装順と受入条件 |
| `docs/knowledge/artifacts.md` | 成果物の実状態 |
| `PUBLIC_READY.md` | 公開前の人間レビュー状態 |

将来の会話生成、外部モデル、3D表現、クラウド実行は決定論コアの外側にadapterとして追加し、同じmanifestとreplayを壊さない。
