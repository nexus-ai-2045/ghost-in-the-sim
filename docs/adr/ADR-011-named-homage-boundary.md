# ADR-011: ポセイドン正本と名称オマージュ境界

- Status: Accepted
- Date: 2026-08-29
- Decision owner: human

## Context

旧正本は独自仮称ハーバー・ループと匿名の実働調整官を採用し、公開面から第三者作品の固有識別子を一律排除した。その境界では、ユーザーが求める遊び心、明示的オマージュ、御影冴を中心にした二次創作的体験を表現できない。一方、名称採用を第三者表現の無制限な複製許可にすると、出典、公式性、公開判断が曖昧になる。

## Decision

1. 舞台名を海洋複合都市圏 **ポセイドン**、主人公を **御影冴**、実働班を **接界機動班**として設定正本へ採用する。
2. 本作を「名称オマージュを明示する非公式の二次創作的プロジェクト」と位置づける。
3. 名称と抽象的テーマへのオマージュは、出典・非提携・非公式を明記した文書で許容する。
4. 第三者作品の本文、台詞、人物名、部隊名、人物造形、事件、外見、ロゴ、画像、音声、画面構成の複製は禁止する。
5. 神話名は `docs/world/naming-taxonomy.md` に役割を固定し、クトゥルフ系は原典と後世設定を区別する。
6. IP検査は全追跡テキスト面をfail-closedで走査し、意図的な帰属・決定文書だけを明示除外する。
7. 本決定はコード・PRの公開を遡及的に承認しない。応募、リリース、告知、広域共有は `PUBLIC_READY.md` の人間レビューを別途必要とする。

## Consequences

- 世界観とUIに一貫した遊び心を持たせられる。
- 「完全独自」という旧説明は使えず、帰属と公開レビューの運用負担が増える。
- ADR-007の旧名称決定と旧一律排除契約は本ADRにより一部supersedeされる。
- 設定採用と実装状態を分離しないと、文書だけの要素を完成機能と誤認するため、ADR-012の状態契約を適用する。

## Alternatives

- 完全独自名称を維持: 法的・運用上は単純だが、ユーザーが求めるオマージュ体験を失うため不採用。
- 公式世界と同一と主張: 許諾・権利・期待の問題があるため不採用。
- 名称だけ無記録で使用: 境界が監査不能になるため不採用。
