# ADR-001: 固有IPではなくオリジナル主体モデルを使う

- 状態: 採用
- 日付: 2026-08-24

## 背景

本プロジェクトの出発点には、ネットワーク化・複数性・異なる視点による危機対応を扱う創作作品から得た着想がある。

## 決定

実装・データ・UI・文書は、オリジナルの主体、シナリオ、用語、アセットだけで構成する。原作の人物、台詞、画像、ロゴ、本文、OCR、アーカイブ、世界設定を利用しない。

## 理由

権利境界を守りつつ、抽象的な着想を比較可能で独自のシミュレーション契約へ翻訳するため。

## 帰結

着想の説明を実装根拠にしない。各主体の目的・制約・関係は、このrepoで独自に定義し、出典と設計仮説を分けて記録する。
