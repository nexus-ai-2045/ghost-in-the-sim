# ADR-010: 卓越した実働者の視点を中心体験にする

- 状態: 一部をADR-011で置換
- 日付: 2026-08-29
- owner: `ghost-in-the-sim`
- related: `ADR-001`, `ADR-003`, `docs/world/setting-bible.md`, `docs/architecture/operative-contract.md`

## Context

既存MVPは三つの統治方式を比較できるが、プレイヤーが誰として何を体験するかが弱かった。ユーザーは、近未来日本の公共危機へ介入する非常に優秀な電脳的実働者の体験を求めている。一方、特定作品の人物・組織・世界観を再現すると、独自性と公開境界が崩れる。

## Decision

プレイヤーを架空組織の実働調整官とする。主人公は開始時から最高水準の身体運用、情報処理、自己監査、現場判断、委任能力を持つ。難易度は能力不足ではなく、同時性、真正性、価値衝突、不可逆性、自己関与から作る。組織・班・主人公のCanonical名称はADR-011および設定正本に従い、現在は「境界事象調整局・接界機動班」「御影冴」とする。

世界観は `docs/world/setting-bible.md`、実装写像は `docs/architecture/operative-contract.md` を正本とする。

## Allowed

- 高性能な複数接続・遠隔身体・AI協働という抽象的な体験
- 独自の組織、事件、人物、用語、状態、指標
- 成功と代償を同時に記録する型付き行動
- provider-neutralなローカル実行と将来の外部実行

## Prohibited

- 特定作品の人物、部隊、ロゴ、外見、台詞、事件、UI、固有設定の再現
- 「公式」「続編」「その人物になれる」など混同を招く表示
- 卓越性を無謬性、無制限監視、無制限権限として扱うこと
- 現実の公安・警察・軍事組織の作戦シミュレーション化

## Human Review Gate

固有名、キービジュアル、ロゴ、キャラクターデザイン、宣伝文、外部Providerへのデータ送信は、公開・実行前に人間レビューを必要とする。設定文書の追加だけでは、それらを承認しない。

## Consequences

- 能力成長より、注意配分、委任、訂正可能性、責任の引受けがゲームの中心になる。
- 既存の三方式比較とAI判断replayを主人公視点へ接続できる。
- 高性能さを維持しながら、簡単になりすぎない構造的な難易度を作れる。
- UI、シナリオ、指標は今後この正本へ段階的に追従させる。
