# ADR-007: 参照資料の版番号と架空都市名の公開境界

- 状態: 一部をADR-011で置換
- 日付: 2026-08-24

## 背景

公式サイトから参照される構想ペーパーは、保存ファイル名と表紙の版表記が一致していると確認できていない。また、旧架空都市名は第三者作品の設定利用と誤解される可能性がある。

## 決定

1. 正式な版番号を一次資料間で確認できるまで、公開文書で特定の版番号を断定しない。
2. 旧架空都市名を廃止し、独自名称「ハーバー・ループ」へ置換する（名称とオマージュ境界は後にADR-011で更新）。
3. 第三者作品の地名、人物、固有設定、画像、台詞、作品風表現を再現しない。
4. 公式な提携、協力、許諾を示す表示をしない。

## 検知と修復

`tests/check_design_contract.py` が未確認の版番号と非公開識別子を検出し、公開境界の説明が欠けた場合に失敗する。正式な一次情報を得た場合は、根拠URLと確認日を記録した別PRで更新する。
