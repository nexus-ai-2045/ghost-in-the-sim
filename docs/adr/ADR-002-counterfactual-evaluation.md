# ADR-002: 単一の結論ではなく反実仮想比較を採用する

- 状態: 採用
- 日付: 2026-08-24

## 決定

同じシナリオとseedを保ち、調整方式だけを変える条件A/B/Cを比較する。A↔Bでは権限・検証経路、B↔Cでは接続負荷だけを変える。Cは独立した統治方式ではなくBのストレス条件とする。単一の総合点で勝者を決めず、複数指標と失敗runを表示する。

## 理由

多主体社会の設計では、速度、証拠、生活継続、異議、依存の間にトレードオフがある。最適解を先に埋め込まず、何が変わったかを観測する。

## 帰結

比較不能な物語生成だけではMVP完了としない。seed、条件、モデル設定、ログを保存する。条件以外のrun identityが一致しない比較、A/B/Cの一括順位、価値の重みを暗黙に置いた総合勝者は採用しない。
