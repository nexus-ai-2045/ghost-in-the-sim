# ADR-006: 再現可能な実験ループを先に実装する

- 状態: 採用
- 日付: 2026-08-24

## 文脈

設計文書だけでは、比較条件が都合よく変わったり、結果が再現できなかったりする問題を防げない。Web UIやLLM接続を先に置くと、モデル本体の振る舞いと表示・生成の差を切り分けにくい。

## 決定

標準ライブラリだけの決定論コアを先に置く。`condition × seed × turn_limit` をmanifestに記録し、同一seedでの条件比較（common random numbers）を明示する。イベントはJSON Lines、結果は機械可読JSONへ出力する。

## 結果

- 同一入力の再実行、条件差、イベント契約をテストできる。
- 出力は仮説比較であり、現実予測・政策助言・最適解の宣言には使わない。
- LLMアダプタやUIはこの入出力契約を満たす別レイヤーとして後から追加する。
