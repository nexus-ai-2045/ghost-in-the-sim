# 一枚設計｜Ghost in the Sim

世界観、主人公、組織、最初の事件は [世界設定正本](../world/setting-bible.md) が所有する。この文書は、その設定を比較実験として成立させる構造だけを所有する。

## 目的

日本をモデルにした架空社会の複合危機を、複数のAI主体がどう解釈し、検証し、説明し、可逆的な行動へ落とすかを比較する。狙いは未来の的中や現実の意思決定ではなく、**領域のあいだを走る連鎖と、調整方式の副作用を見える化すること**である。

## 中心仮説

部分観測・異議・根拠の来歴を残す多元型の調整は、短期的には遅く見えても、誤認訂正・生活継続・説明責任を改善しうる。一方で、接続の増加は合意の遅延、情報漏洩、責任の曖昧化、特定の翻訳者への依存も生みうる。

この仮説を正解として埋め込まない。統制型が優位になる条件と、多元型が失敗する条件も同じ測定系で出す。

## MVP

### 架空の世界

舞台は港湾・物流・医療・地域メディア・クラウド連携が接続された海洋複合都市圏「ポセイドン」。危機対応AIの複製が通信分断で異なる記憶・方針・権限世代を持ち、誤観測と失効遅延が重なる。特定の国・組織・個人・実在する攻撃手法はモデル化しない。

### 主体

| 主体 | 守りたいもの | 典型的な制約 |
|---|---|---|
| 連携調整室 | 生活継続と説明責任 | 権限は限定的、判断を急がされる |
| 基盤運用者 | サービス継続と安全 | 全情報を共有できない |
| 港湾・物流連携者 | 物流維持と現場安全 | 物理制約と契約制約 |
| 地域連絡者 | 住民の理解と支援 | 断片情報と感情の揺れ |
| 独立検証者 | 根拠の妥当性 | 行動権限が小さい |
| 報道・情報仲介者 | 速報性と訂正可能性 | 不確かな情報に接触する |

各主体は役職ラベルではなく、目的、関係、経験、部分観測、禁止行為、変更可能な信念を持つ。詳細は [エージェント契約](agent-contract.md) を参照する。

### 比較する条件

| 条件 | 調整方式 | 期待する反証 |
|---|---|---|
| A: 統制型 | 一つの調整室が情報と発信を強く集約する | 速いが誤認訂正や局所事情の反映に失敗する可能性 |
| B: 多元型 | 検証・地域連絡・運用を複線化し、異議を可視化する | 訂正や説明は強いが、遅延や責任分散が起こる可能性 |
| C: 接続過多 | Bに過剰な通知・共有を加える | 多元性そのものではなく、接続設計が重要だと示す |

### 観測指標

単一スコアで勝敗を決めない。生活継続、証拠校正、訂正に要したターン、異議が失われずに届いた割合、調整ノード依存、情報開示の過不足を並べる。

## 成功・失敗の扱い

成功は「中央が勝つ」ことではない。関係者が根拠・留保・次の可逆的手を追跡でき、特定主体が止まっても必要最小限の協調が続く状態を成功候補とする。

次は失敗または仮説の縮小として扱う。

- 多元型が、追加情報や特別な善意を与えないと成立しない。
- 統制型より多元型が常に良く、トレードオフが観測できない。
- seedやモデルを変えるだけで結論が一貫して反転する。
- 主体の違いを消しても同じ結果となり、部分観測を持たせる意味がない。

## スコープ外

- 実在する安全保障機関・政策・作戦・攻撃手法の再現または推奨
- 個人・組織の能力評価、帰属判断、予測
- 原作作品の登場人物・台詞・画像・世界設定の再利用
- 実世界に対する自律行動や外部システム制御
