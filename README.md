# Ghost in the Sim

複数の立場・記憶・制約を持つAIエージェントが、日本の複合危機をどう異なって観測し、対話し、介入案を比較するかを考えるメタ安全保障シミュレーションの概念ラボです。

> 現在は設計段階です。実在組織・政策・安全保障上の行為を指示するものではありません。

## 目的

単一の「正しい司令塔」に寄せず、異なる視点が持つ部分観測・異議・説明責任を残したまま、モノ、組織、意味の三相をまたぐ連鎖を観測できる最小シミュレーションをつくります。

## できること（予定）

- 危機シナリオに対する複数参加者の部分観測を記録する
- 見立て、質問、提案、留保をターンごとに比較する
- 安全、インフラ、信頼、証拠確度、権利影響などの状態変化を追う
- 合意を急ぐ場合と異議を残す場合の連鎖の違いを検討する

## はじめ方

実装は未着手です。今は以下を読んで、テーマとシナリオをレビューしてください。

1. [公開前チェック](PREFLIGHT.md)で扱う範囲を確認する。
2. GitHub IssueまたはDiscussionで、最初に観測したい二領域と事象を提案する。
3. 採用されたシナリオは、再現条件・状態変数・評価観点を明記して実装する。

## 創作作品との関係

本プロジェクト名と着想は、ネットワーク化、複数性、異なる視点による危機対応を扱う創作作品から影響を受けています。ただし、特定の作品・キャラクター・組織・台詞・画像・ロゴを再現または利用せず、権利者・制作側・公式企画との関係も主張しません。

公開される実装・資料は、オリジナルの参加者モデルとシナリオだけで構成します。

## 限界

- シミュレーションは現実の予測器でも、実在組織への助言でもありません。
- LLMの出力は仮説であり、事実確認・法的判断・危機対応の代替にはなりません。
- 機密情報、個人情報、第三者著作物の本文・画像・OCR・アーカイブは扱いません。
- 最初の具体的シナリオ、評価指標、ライセンス対象となる実装物は未確定です。
